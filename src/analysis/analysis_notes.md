# Analysis Notes

This document summarizes the active downstream analyses that use intermediate or final outputs from the core targPred workflow. Each analysis has a corresponding source directory under `src/analysis/` and writes analysis-specific results under `data/analysis/`.

The non-coding gene analysis is not part of the current documented workflow.

## Common Inputs From Core

| Name | Type | Description | Location |
|---|---|---|---|
| `loci_in_GRBs.df.csv` | CSV | Core table of GWAS loci that overlap GRBs, with SNP, trait, LD block, GWAS gene, and GRB target gene annotations. | `data/processed/` |
| `GRBs_with_targets.gr.rds` | RDS / GRanges | GRB intervals with target gene metadata. | `data/processed/` |
| `<byGRB_name>` | RDS / list | by-GRB object containing genes, enhancers, and empP information for GRBs. | `data/processed/` |
| `gwas_associations.csv` | CSV | GWAS associations after core processing and LD block assignment. | `data/outputs/` |
| `web_table.csv` | CSV | Core web/output table used for summary counts. | `data/outputs/` |

### Key Steps

1. `coding_variant_download_clinvar.sh` downloads and filters the ClinVar GRCh37 VCF.
2. `coding_variant_processing.R` maps ClinVar disease annotations to the ontology IDs used in the core GWAS/GRB table and writes ClinVar gene-disease mappings.
3. `coding_variant_analysis.R` compares ClinVar genes with GWAS genes and GRB target genes for matched traits and produces Venn diagrams.
4. `alsheik2022_analysis.R` joins the Alsheikh 2022 validated GWAS set to `loci_in_GRBs.df.csv` by SNPs and traits, then compares validated genes with GWAS and GRB annotations.
5. `ABC_exploration.R`, `GH_exploration.R`, and `cS2G_exploration.R` prepare external enhancer-gene benchmark datasets for comparison with GRB enhancer-promoter annotations.
6. `ABC_plots.R`, `GH_plots.R`, and `cS2G_plots.R` generate score distributions, category comparisons, statistical summaries, and supplemental tables.

## 2. Crude Numbers

**Goal:** Combine loci in GRBs with enhancer-promoter links to summarize disease-associated EP links for GRB targets and bystander genes.

**Code directory:** `src/analysis/crude_numbers/`

**Data directory:** `data/analysis/crude_numbers/`

| Name | Type | Description | Location |
|---|---|---|---|
| `<byGRB_name>` | RDS / list | by-GRB object from the core pipeline. | `data/processed/` |
| `GRBs_with_targets.gr.rds` | RDS / GRanges | GRB target annotations from the core pipeline. | `data/processed/` |
| `empP_CAGEenhPermissive_hg19Ens_6.4Mb_chr*.txt` | Text files | Chromosome-level empP files. | `data/processed/<empP_dir>/` |

### Outputs

| Name | Type | Description | Location |
|---|---|---|---|
| `EP_dist_df.csv` | CSV | Enhancer-promoter distance table used for downstream EP summaries. | `data/analysis/crude_numbers/outputs/` |
| `loci_EP.csv` | CSV | Unlisted by-GRB enhancer-promoter table with empP values and categories such as GWAS bystander and GRB target. | `data/analysis/crude_numbers/outputs/` |
| `nested_pie_plot_white_v1.svg` | SVG | Summary plot showing GWAS SNPs, fraction in GRBs, new annotations, and FANTOM5 enhancer overlap. | `data/analysis/crude_numbers/outputs/` |
| `number_of_enhancers_cumulative_binned_distance_target_gene_v7.svg` | SVG | Distance-binned enhancer count summary by target/bystander category. | `data/analysis/crude_numbers/outputs/` |
| `number_of_enhancers_cumulative_binned_distance_target_gene_test.csv` | CSV | Wilcoxon/statistical summary for binned enhancer counts. | `data/analysis/crude_numbers/outputs/` |
| `crude_numbers.txt` | Log file | Log for crude-number analysis. | `data/processed/logs/` |

### Key Steps

1. `loci_EP_counts.R` generates `loci_EP.csv`, which is essentially an unlisted by-GRB list containing disease-associated enhancer-promoter pairs, empP values, and category labels.
2. Multiple testing correction is applied on the GRB level using FDR. Enhancer-gene pairs are considered significant when adjusted p-value is below the chosen threshold.
3. Enhancer-promoter pairs are binned by distance and summarized as cumulative enhancer counts per bin.
4. `crude_numbers_manuscript_plots.R` produces manuscript-style summary plots, including nested pie charts and binned enhancer-count plots. Transcripts with zero expression across samples are excluded.

**Code directory:** `src/analysis/LRR_pheno/`

**Data directory:** `data/analysis/LRR_pheno/`

### Inputs

| Name | Type | Description | Location |
|---|---|---|---|
| `loci_in_GRBs.df.csv` | CSV | Core loci-in-GRB table. | `data/processed/` |

| `gwas_associations.csv` | CSV | Core GWAS association table. | `data/outputs/` |
| `EFO_terms.rds` | RDS | EFO ontology terms used to classify traits. | `data/inputs/` |
| `gwas-efo-trait-mappings.tsv` | TSV | GWAS-to-EFO trait mapping file. | `data/inputs/GWAS_2026/` |

### Key Steps

1. `extracting_per_trait_data.R` creates trait metadata and category assignments for downstream per-trait analysis.
2. `overlapping_snps_enh_perTrait.R` creates per-trait SNP/empP overlap objects using core GWAS/GRB outputs and chromosome-level empP files.
3. `run_grb_shuffle_per_trait.sh` is a job script that runs the GRB shuffle analyses inside the container.
4. `grb_shuffle_per_trait.R` and `grb_shuffle_per_trait-2.R` calculate observed statistics, null distributions, and empirical p-values from shuffled intervals.
5. `empirical_exploration.R` and `wilcox_res_plots.R` summarize empirical p-values, null distributions, and trait-level distance differences.
